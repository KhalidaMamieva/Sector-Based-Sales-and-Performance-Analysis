# Sector-Based-Sales-and-Performance-Analysis
Sektorlar Üzrə Satış və Performans Analizi
"Data analitika bootcamp" çərçivəsində hazırladığım 2 səhifədən ibarət 2-ci sərbəst layihəmdir. Layihədə müxtəlif biznes sektorları üzrə satış göstəriciləri, gəlir paylanması və ümumi performans təhlil edilərək vizuallaşdırılmışdır.
